# 云岁月对接类目上新指引 - 升级完整包

直接把本压缩包解压后的全部文件上传到 GitHub 仓库根目录，保持目录结构不变。

重点：
1. assets/compliance/：两个首页合规 PDF。
2. assets/styles/padded/：已从“棉羽绒(1).pptx”提取并转换为 WEBP 的网页图片，文件名全部为英文 ASCII，适合 GitHub Pages 路径。
3. source-files/：类目路径表和标题词库原文件。
4. data/category-data.js：按“云岁月对接路径表.xlsx”整理，共套装 35 条、正装 11 条、棉羽 14 条路径。
5. data/open-direction-data.js：套装/正装 PDF 参考 + 棉羽 WEBP 图片参考。
6. GitHub Pages 根目录必须使用 index.html。
