TEMU 男装运营工作台
云岁月 · 商家工具

男装上新、开款、视觉与标题
一站式运营工作台

围绕套装、棉羽、正装三大类目，连接精准上新路径、开款参考、视觉 Prompt、标题组合与后续招品回品。

模块 01

类目指引

先总览全部路径，再选择套装、正装、棉羽进入精准上新路径。

原始类目表：下载 Excel｜已整理为网页可复制路径
模块 02

开款方向

套装、正装、棉羽三大类款式参考。优先显示图片；无图片时自动显示对应 PDF 页面。

模块 03

视觉优化

按人模、姿势、风格、场景、配饰、光线与构图组合生成中文电商图片 Prompt。

生成的视觉 Prompt
模块 04

标题优化

按套装、正装、棉羽选择核心品类词、版型、风格、材质、细节、场景等关键词生成英文标题。

标题黄金公式：[件套规格 (2pcs/3pcs)] + [人群/品类] + [版型/风格] + [材质/图案] + [领型细节] + [包含部件说明] + [多场景/卖点]
生成的英文标题
模块 05

招品 / 回品

预留招品清单、回品判断、趋势数据与选品评分入口。

招品 / 回品功能已预留

后续可直接在 app.js 中继续增加招品链接、回品规则、趋势数据和评分模型。
